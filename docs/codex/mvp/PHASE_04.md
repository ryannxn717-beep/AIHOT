# 导航结构与模型榜

## 用户确认的规格

主导航五项：AI 动态（精选动态、全部资讯、热点榜、AI 日报）；主题（公司与模型、技术方向、内容类型）；模型榜；出海建站；SEO 内容。后两项只显示未开放，不创建可访问业务页面。关于、更新日志、反馈进入辅助菜单，收藏和接入仍可访问。

视觉延续用户选定的简洁文字布局，不加入装饰图片。桌面和手机都可展开前两个菜单，支持键盘、Escape 关闭和选择后的收起。主题菜单进入对应分组，保留原主题地址和范围筛选；不删除原报告中心和周月报地址。

模型榜采用 LiveBench 官网当前公开表格快照（2026-06-25 评测版本，2026-10-10 核验），保留模型完整配置名、机构、开源权重标记和各维度实际分数。按公开分数排序，同分并列，搜索不改变名次。标明单一评测来源、版本与核验时间；不冒充参考站多机构综合分，不把快照称为实时。页面加载不抓外部来源、不调用模型。首次接入采用人工核验快照，自动同步不在本轮范围。

## 第一性原理与取舍

既有栏目已能读取真实发布内容，根问题是导航分组与缺失的榜单数据。复用原链接加下拉即可解决前者；后者需要独立的一手评测来源。更简单的榜单外链不能提供站内排序；拒绝复制参考站评分或用模型生成排名。少量专属模块负责榜单页面与 HTTP 路由，公开读取统一放在 packages/backend/src/publication/，前端只通过 HTTP 读取。

风险：公开快照会过时，必须展示核验日期；评测任务与普通用户真实体验不同，维度按来源命名，不伪装成办公或科研专项测试。来源字段变化必须拒绝无效快照。无数据库迁移、真实模型调用、基础设施修改或生产部署。

## 验证证据与限制

新需求 SSR/浏览器测试先红：旧导航无下拉、主题没有 group 筛选、/leaderboard 返回404。实现后针对性11项通过。模型榜校验与HTTP出口独立4项通过；最终后端735项、Web67项通过，类型检查/构建通过，smoke38项通过。

独立审查发现点击当前菜单地址不收起；加入真实浏览器断言先复现红灯，再通过链接点击关闭所属菜单解决，复审APPROVE。审查逐项比对LiveBench实际可见表格与快照，60配置和8维成绩无缺失或差异；390/320px展开成绩无横向溢出，未开放的/overseas和/seo均404。

本机浏览器复核桌面AI动态四项、手机主题三项下拉，以及编程榜搜索DeepSeek后保留完整名次；390px页面宽度为390px。截图位于被忽略的.data/screenshots/phase04-navigation-desktop.png与phase04-navigation-mobile.png。原报告中心的手机离线返回回归仍通过。

没有生产部署或开启采集、模型、推送。榜单尚未自动同步；没有参考站的跨机构综合评分、专用监控或主题大事记。本站内容量超过参考站仍未达成；榜单配置数不能代替资讯数量。
