# 正式网站准备阶段

## 目标与边界

用户确认继续建站。沿用已批准的独立导航、重点阅读和中文资讯风格；本阶段先改善内容发现及来源透明度，使页面在少量内容时也可用，随后交付部署前可检查的配置清单。

域名aihot.lol、GitHub目标及上游技术栈已确定。模型服务、每日预算和服务器平台仍待用户补充，异步问题已发出；不启用付费请求、不改DNS、不部署未经确认的生产环境。

## P0 范围

- 主题页默认展示有已收录内容的主题；可切换到全部已配置主题。按上游API的total判断，不捏造篇数。
- 关于页增加公开来源样本的搜索、类型/用途说明。样本不冒充完整名单；缺失统计不显示为零。
- 站点介绍说明实际阅读方法，避免配置了信源就声称已经定时采集或每天出刊。
- 保留API、SSR、缓存、手机导航和已有来源归组逻辑。分类、评分及付费调用保持原状态。

## 取舍

推荐复用原API并重组页面。更简单的方案只写一段来源说明，无法帮助读者在稀疏主题中发现内容。拒绝新增来源库或另一个内容API，现有SiteStats和TopicsResponse已经提供本阶段需要的数据。

自动处理失败和公网DNS兼容问题属于后续采集阶段；生产环境必须保留原SSRF防护。近30天去重有效内容超过参考站的目标没有被本阶段界面改进替代。
