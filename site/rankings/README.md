# 模型榜快照

`livebench.json` 保存 LiveBench 官网公开榜单的可见成绩与模型配置名。来源 https://livebench.ai/#/?showorg=1 ，评测版本 2026-06-25，2026-10-10 核验，60 个模型配置，综合与七个专项维度。采集时未勾选 Include finetunes，保留官网该视图实际展示的配置，不把这些配置数量称为模型厂商数或全部评测覆盖数。

这些是来源公布的评测事实，不是本站独立测试结果。模型完整名中的 Effort/Thinking 等配置保留；开放权重状态沿用来源标记。费用列未收录，不推断 API 价格或普通用户订阅费用。综合分沿用来源各类平均分；本站按已公布的一位小数排序，同分并列，不尝试恢复未知的原始精度。

## 更新

本轮没有启用自动同步。更新前打开官方榜单，确认评测版本、选项、表头及模型配置；核对所有行的名称、机构、权重标记和八项成绩，再替换快照并更新 source.release/source.observedAt。核验日期指人工核对时间，不冒充来源发布或最后更新日期。缺少分数不得补成零，也不从新闻或模型回答中猜测名次。

运行 `node --test modules/rankings/tests/rankings.standalone.test.ts` 校验字段、分数范围、唯一名称与并列排序；检查 diff 后按正常代码发布流程更新运行站点。API 只通过 `packages/backend/src/publication/rankings.ts` 读取快照，前端通过 HTTP 获取；缓存最多五分钟，访问页面不取外部网页、不调用模型。

若来源停止公开、改变口径或字段，先停止更新并核验，不以旧日期标新快照。接入其他机构的成绩时需保留各自版本与口径，不直接平均不同评测的原始分数。
