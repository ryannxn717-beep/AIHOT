页首说明：

> 使用 AI 简报不需要注册或登录。本站处理提供阅读服务和接收反馈所需的信息。

## 1. 浏览器本地数据

收藏、已读记录、外观设置、最近搜索和反馈草稿保存在当前浏览器。列表位置和展开状态保存在当前标签页的会话存储。这些记录不用于跨设备同步；清除浏览器数据后会消失。搜索词会随搜索请求发送到本站，以返回结果。

## 2. 反馈

提交的文字、选填邮箱、页面地址会保存在本站数据库，用于处理反馈。当前免费 MVP 不接收截图附件，也未启用飞书转发。防滥用标识由网络地址和浏览器类别经密钥散列生成，用于限流；反馈记录不向其他访客公开。

反馈记录没有自动到期删除机制。需要查询、更正或删除已提交资料时，请通过反馈页联系维护者并提供反馈编号；不要在公开 Issues 中发布邮箱、密钥或其他私人资料。公开联系邮箱稍后补充。

## 3. 托管服务

网页与 API 使用 Cloudflare Workers，反馈与内容数据库使用 Neon。服务商会处理请求的网络信息及托管数据，以提供服务。本站未启用第三方访客分析、广告追踪或 Workers 请求日志存储；平台自身仍可能依其规则处理安全及运行信息，详见 [Cloudflare 隐私政策](https://www.cloudflare.com/privacypolicy/) 与 [Neon 隐私政策](https://neon.com/privacy-policy)。

## 4. 原文链接

本站展示公开来源的摘要与原文链接。点击原文或 GitHub Issues 后将访问第三方网站，适用对方的隐私规则。请勿在反馈中提交与问题无关的敏感信息。
